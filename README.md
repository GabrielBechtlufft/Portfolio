# Gabriel Bechtlufft — Portfolio

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro, com foco em performance, animações fluidas e design minimalista.

**[gabrielbechtlufft.dev](https://github.com/GabrielBechtlufft/Portfolio)** · Jacareí, SP

---

## Stack

- **HTML / CSS / JavaScript** — sem frameworks, sem dependências desnecessárias
- **GSAP + ScrollTrigger** — loader animado, cursor customizado, scroll reveals e parallax
- **Google Fonts** — Bebas Neue + Space Grotesk
- **Design** — tema escuro (`#080808`), acento neon (`#d4ff00`), tipografia editorial

## Rodando Localmente

Não requer build. Basta abrir o `index.html` no browser ou usar um servidor estático:

```bash
# com Node.js
npx serve .

# com Python
python -m http.server 3000
```
